# 本目录模型维护要求

适用于本目录及 tools/。用户已明确要求后续优化同步更新 SVG，并保持易读、逻辑清晰。

- 修改业务模型后，必须同步相关 .puml、tools/build_svgs.py、SVG 与正文索引；执行生成脚本，不只交付源文件。
- 固定排版脚本是当前 SVG 的生成源，.puml 是模型语义源；不要用 PlantUML 自动输出未经检查覆盖设计后的 SVG。
- 主线与异常分开；复杂领域图拆分；关系端点、数量、守卫条件和编号须正确。不能为视觉简化添加不存在的关系。
- 原尺寸文字保持可读，不让节点或连线遮挡文字；空间不足优先扩大画布或分图。
- 每次变化均完成 XML/边界检查与实际渲染视觉检查；修订过的图要复查，明确区分图示 QA 与业务执行测试。
- 同步课堂用例图副本，保留历史归档和原 ZIP。
