## 上传范围与限制

本次上传文本材料、10个PlantUML语义源、13张SVG、图册、生成与材料检查脚本及证据说明。未上传原始ZIP、PlantUML jar、环境安装包、.DS_Store、Vim交换文件和个人智能体缓存。课程要求恢复片段明确不完整，不能代替完整原件。

原始ZIP及课堂材料副本仍在本地；文档中引用的ZIP和部分本地材料不在此仓库快照内。材料检查脚本中的ZIP字节核验、课堂副本核验需要原本地工作区，不能在仅下载本目录时直接宣称全部通过。文件清单和已有检查结果记录本地检查范围，不表示仓库内容已经完成业务测试。

SVG使用Python标准库生成，进入模型目录执行 `python3 tools/build_svgs.py`；脚本从语义源配套维护固定排版，修改后应重新生成并检查图示。历史归档不覆盖，仓库现有根README保持原样。
