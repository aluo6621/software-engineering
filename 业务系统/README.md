# 校园流转业务系统 v0.2

需求依据：校园二手交易平台V2.0及UD-09。技术栈：Node.js（≥24，需内置node:sqlite）、SQLite、原生HTML/CSS/JS，无第三方运行依赖。与课程模拟原型独立。

## 本地启动

在本目录执行：

```sh
npm run setup
npm start
```

Windows PowerShell也可使用：

```powershell
npm.cmd run setup
npm.cmd start
```

浏览器访问 http://127.0.0.1:3000 。管理员用户名为admin，初始密码见自动生成的`.env`；不要提交该文件。setup不覆盖已有配置。管理员仅首次建库时初始化，修改.env不会重置已有密码。

数据库在data/campus.sqlite，保存用户、认证、头像、商品图片、订单、私信及事件，重启保留。已有数据库启动时自动增加本版字段与表，不清空旧记录。首次没有学生账号或商品，需要自行注册、申请认证、管理员审核后发布与交易。

本地仅监听回环地址。跨网络部署前需配置HTTPS、COOKIE_SECURE=1、反向代理请求限制及备份，不将开发版直接作为公开服务。

## 当前实现

- 独立登录/注册页、确认密码、显示密码、注册后选择认证或跳过；scrypt密码哈希、HttpOnly/SameSite会话、CSRF、失败锁定与服务端权限。
- 姓名学号认证、申请历史和管理员线下核验审核。重复已认证学号在提交时拦截，审核保留重复检查；按认证状态展示申请入口或进度。
- 只读个人主页与独立编辑页，昵称/简介/头像一次保存；头像支持原图15 MiB以内的PNG/JPEG，浏览器裁剪压缩至512×512后上传，后端成品上限2 MiB。
- 管理工作台仅管理员显示。公开学生主页展示头像、用户名、昵称、简介、认证状态与在售商品，不展示认证姓名、学号。
- 出售/免费转让/交换、图片存SQLite、基础内容标识/大小/数量检查、20件配额、先审后上架、本人发布列表。整卡点击，无商品时按身份引导。
- 发布须填写建议交货地点，商品详情及订单展示；下单保存地点快照，实际交付信息单独展示。旧商品无地点时提示协商。
- 下单快照、私有交换提供项与差价、请求去重、事务和进行中唯一索引。交换详情同卡展示双方信息及操作。
- 接单、拒绝、接单前取消、接单后协商取消及撤回、交付记录、本人双确认完成；服务端截止检查与超时任务，订单事件和本人通知。
- 商品联系卖家、订单联系对方；同商品及同双方复用私信会话。文字消息、历史分页、未读/已读、发送重试去重。聊天每5秒更新，其他页面约15秒更新未读，隐藏页面暂停；自动更新保留输入草稿。
- 会话列表和聊天标题显示头像，标题可进入对方主页。发送需已认证学生，聊天记录仅双方可见，管理员不可读取。
- 异常JSON请求统一返回400与明确错误，不因null请求触发500。

详见[本版改动](docs/版本改动-0.2.0.md)与[UI优化记录](docs/UI优化记录.md)。

## 验证

```sh
npm test
```

PowerShell也可运行`npm.cmd test`。测试使用内存SQLite、真实本地HTTP请求及可控业务时钟，不使用或清空开发数据。

本版三组集成测试覆盖交易/认证、资料/头像、私信权限/幂等/已读/历史分页、异常输入及无副作用。浏览器实测覆盖注册、卡片、交换详情、个人主页编辑、头像裁剪压缩、私信收发及草稿保留。旧数据库补列和重复启动检查通过。

实际验证平台为macOS，Windows尚未运行验证。这些检查不代替全部35项VT、跨浏览器矩阵或性能验收。

## 限制与后续开发

1. 商品编辑重审、上下架重上架和分类维护仍待完善。
2. 收藏、评价及回复、举报及证据、私信图片消息尚未实现。
3. 管理员异常订单暂停/恢复/终止、限制封禁解禁、授权与审计查看仍待完善。
4. 身份恢复、7天提醒、通知去重重试、校园地图选点、统计、备份恢复与性能兼容验收后续实现。

后端图片基础标识检查不等于完整图像解码和恶意内容检测，浏览器裁剪不能替代服务端重编码与像素限制。基础HTTP与SQLite用于课程本地开发，不据此承诺生产容量。
