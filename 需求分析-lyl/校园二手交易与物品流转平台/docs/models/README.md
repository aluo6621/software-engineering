## 生成与同步

SVG 采用固定坐标排版，生成源为 `tools/build_svgs.py`；.puml 保留模型语义，当前 SVG 不是 PlantUML 自动导出，二者内容需共同维护。当前不依赖 Java。

```bash
python3 tools/build_svgs.py
```

命令可在任意目录执行（路径按实际位置指定），会覆盖本目录的 13 张 SVG、重建图册并同步课堂材料的用例图。不要仅修改生成的 SVG，否则下次重建会覆盖修改。

若选择用 PlantUML 检查 .puml 语法，可安装 Java 后运行 jar；其自动布局结果不是本套固定排版版本，不要未经检查覆盖同名 SVG。当前未验证 .puml 编译成功。

## 后续维护规则

1. 修改需求规则时同步 `.puml` 语义源、`tools/build_svgs.py` 中相应图示内容，再重建 SVG；不能让旧图继续冒充当前版本。
2. 每图说明阅读方向；正常主线与异常/回退分开；领域关系须保留数量与方向语义，不能为减少线条误连对象。
3. 避免连线穿过文字或节点，标签不得压在框线和箭头上；空间不足应分图、换行或扩大画布，不依靠缩小到难读字号解决。
4. 使用统一中文字体、颜色和间距；原尺寸正文建议不低于 15 px，辅助标签不低于 13 px；色彩之外同时使用文字区分状态。
5. 重建后逐张渲染，检查完整画布、文字裁切、节点遮挡、分支箭头、条件及编号。语义或版式变化的图必须再次视觉检查。
6. 图册、正文图索引和课堂材料副本随同更新；历史归档与原 ZIP 不修改。
