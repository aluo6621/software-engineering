# v0.2.0 改动说明

日期：2026-10-30。基于原生HTML/CSS/JavaScript、Node.js和SQLite，不增加第三方运行依赖。

## 用户流程

- 登录与注册拆分，确认密码、显示/隐藏密码；注册后选择立即认证或跳过。
- 重复学号在申请提交时直接提示，审核保留重复校验；按认证状态展示内容，避免重复申请。
- 商品及订单卡片整体点击；空状态按游客、未认证学生、已认证学生及管理员分别引导；管理入口仅管理员显示。
- 发布填写建议交货地点，商品详情与订单展示；订单保存地点快照，实际交付信息单独展示。校园地图尚未接入。
- 交换详情同卡展示双方物品图片、成色、描述与差价，订单状态、记录及操作一并呈现；接单/拒绝放在右下角并提供绿色/红色悬停反馈。

## 个人中心

- 右上角“我的”进入只读个人主页，点击“修改资料”才进入编辑。昵称、简介与头像一次保存；恢复默认头像也需保存后生效。
- 原图最多15 MiB、4000万像素；浏览器支持拖动、缩放、方向按钮裁剪，输出512×512 JPEG再上传。后端限制2 MiB成品。
- 公开学生主页展示头像、用户名、昵称、简介、认证状态和在售商品；不公开认证姓名、学号、申请记录。

## 私信

- 商品详情联系卖家，订单联系对方；同商品、同双方复用会话。
- 会话列表和聊天标题显示对方头像，标题可进入对方主页。
- 文字消息每条最多2000字，历史分页、未读/已读、请求标识重试去重。聊天页5秒更新，其他页面约15秒更新未读，隐藏页面暂停；自动更新保留正在输入的草稿。
- 发送需已认证学生，聊天记录仅双方可见，管理员不能读取。暂不包含图片消息或系统推送。

## 数据与接口

- 启动时为旧数据库增加商品建议地点、个人资料/头像字段、会话和消息表及索引，不清空原数据。旧商品无地点时提示协商。
- 统一拒绝null、数组和其他JSON原始值，返回400；无效JSON返回明确格式错误，避免500。
- 资料接口只允许修改本人资料；昵称、简介与头像全部校验通过后用单条SQL更新，防止部分保存。沿用CSRF校验。

## 验证与限制

- macOS上执行npm test：三组HTTP集成测试通过。覆盖交易闭环、认证唯一性、资料/头像校验与权限、私信隔离/幂等/已读/分页、异常请求无副作用。
- 浏览器在独立内存数据库验证注册、卡片、交换详情、头像裁剪保存、个人主页和私信收发。3.6 MiB测试PNG裁剪后为512×512、175143字节JPEG。
- 旧数据库补列和重复启动检查通过。Windows尚未实际运行，不宣称Windows验收通过。
- 后端图片为基础内容标识检查，不是完整解码重编码；浏览器裁剪不能替代服务端图像安全处理。完整性能、跨浏览器及全部验收场景尚未执行。
- 本次提交不包含.env、运行数据库、上传图像、真实账号资料、日志、临时测试文件或campus_trade。
