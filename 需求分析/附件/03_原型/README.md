# 校园流转 P1.0 可点击原型

日期：2026-10-29；依据：需求规格说明书V2.0、SC-01～04。所有身份、物品与订单均为虚构数据。

## 打开与操作

用普通浏览器直接打开[index.html](index.html)，保持style.css、app.js同目录；不需安装依赖、登录或启动后台。刷新丢失全部演示数据。顶部可切换虚构买家/卖家/未认证/第三人/管理员；场景起点会重置数据。

- SC-01：发现闲置→台灯详情→买家下单→切卖家接单→记录交付时间（不晚于当前时刻）、地点、说明→双方分别确认。商品发布另从“发布物品”填写资料和本地测试图片，管理员工作台通过/驳回。新发布商品只演示审核队列，不加入固定市场列表。
- SC-02：选择权限场景，尝试未认证下单/咨询；收藏、举报可操作。切第三人查看订单或切非管理员进入工作台，查看拒绝提示。
- SC-03：载入待交付订单；买家填理由申请；自己同意被拒；卖家可拒绝或同意。待回应期间不能记录交付。长期无人回应暂不新增规则（V-15）。
- SC-04：载入待确认订单，切管理员模拟截止；切卖家接单应拒绝，再由管理员扫描关闭。重置后填写依据暂停、恢复或终止。
- 交换补充：填写提供物品、成色、描述、1～6张本地测试图片及差价，提交私有快照订单；无需先发布提供物品。
- 身份认证：切未认证学生，只填姓名、学号；管理员审核。不核验学籍，审核后交易演示须手动切已认证角色。

## 实现与模拟边界

已实现浏览器内页面切换、筛选/搜索、固定商品详情、内存订单状态与双方确认、协商取消、审核队列、通知展示、基础必填/图片MIME大小数量/金额校验、暂停恢复终止、手动超时模拟。

未实现真实认证/登录/授权安全、数据库/接口、跨用户并发/事务、真实文件上传与内容检测、真实时间调度、支付/退款、完整发布20件/收藏100配额、评价14天计时/回复、管理员账号授权、封禁解禁、数据保留备份及统计。管理页数字仅为本次演示队列计数。顶部身份切换为走查工具，不是真实授权机制。原型不承诺支持完整业务或全部35项VT。
